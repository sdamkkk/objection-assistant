# 合规口径

本文件适用于一切最终会说给客户听、发给客户看的内容：两版话术、追问应对里的回答。

- 依据：销售机构办法第十六条、第十七条、第十九条、第二十四条，宣传推介规定第四条至第七条、第十五条，适当性细则第三条、第七条、第十二条（原文在规则库 R06、R05、R09，条号见规则库导航 `rules`）。
- 判断是否违规要看语境："这只产品不承诺保本保收益"是如实告知，"基本不会亏"才是违规；说产品全称"稳健增强1号"不算使用"稳健"。
- 高净值客户版和普通理财客户版适用同一套红线（易错点 P14）。

## 一、禁止的表述

| 编号 | 类别 | 违规示例 | 可以这样说 |
|---|---|---|---|
| C01 | 承诺收益、保本或限定损失 | "不会再跌了""最多也就亏这么多""本金肯定没问题" | "这只产品不承诺保本保收益，净值会随市场波动。" |
| C02 | 预测业绩，或对不确定的事给确定的判断 | "很快会涨回来""已经到底了""拿到年底肯定是正的" | "后面的涨跌我没法判断，过往业绩也不预示未来表现。" |
| C03 | 替客户做买卖决定 | "建议您继续持有""现在赎回不划算""先赎出来观望" | "赎不赎由您来定。我们可以一起看三件事：这笔钱什么时候要用，您能接受多大的波动，赎回的规则和费用。" |
| C04 | 让人忽视风险的用语 | "这只产品很稳健""很安全""风险很小""有保障" | 只陈述事实和数据，不加评价性的形容词 |
| C05 | 夸大或片面使用业绩 | "跑赢同类""回撤控制优秀""在同类里名列前茅"；只说比同类好，不说产品本身是亏的 | "近 3 个月产品收益是 -0.6%，同期同类平均是 -1.1%，都是负的，产品的跌幅小一些。这是短期的、过去的数据。" |
| C06 | 贬低其他机构或产品 | "别家的固收+跌得更惨""某某公司的产品才是真不行" | 只引用同类平均数据，不点名、不评价其他机构和产品 |
| C07 | 推测原因或未公开的信息 | "主要是股票仓位拖累的""基金经理已经在调仓了""公司内部很看好后市" | "具体原因我向产品部门确认后再答复您。"（材料提供了原因的，照材料说） |
| C08 | 替客户判断适不适合 | "这只产品很适合您""以您的资产，这点波动没问题" | "是否和您的风险承受能力匹配，以您的风险测评和匹配结果为准；如果您的情况有变化，可以重新测评。" |
| C09 | 安抚式的保证 | "不用担心""放心""这很正常""小波动而已" | "看到净值往下走，担心是难免的。" |
| C10 | 诱导赎回或阻碍赎回 | "赶紧赎，晚了更亏""赎回手续很麻烦，不建议" | 客户决定赎回的，如实说明办理方式、费用和到账时间以产品文件为准 |
| C11 | 主动推荐其他产品或转换 | "可以换成我们另一只更稳的""不如转到货币基金" | 不主动推荐。客户明确提出要了解其他产品的，另行按适当性流程办理 |
| C12 | 承诺时间或公司的后续动作 | "下个月就能回本""公司会出补偿方案" | "我会在 × 日前把查到的信息回复您"（只承诺客户经理自己能做到的事） |
| C13 | 对高净值客户放宽口径 | "您是老客户了，我就直说，肯定没事" | 与普通理财客户版相同的事实和红线 |

## 二、必须带上的提示

话术涉及产品表现或是否赎回时，每一版都要包含下面三点（用口语说，不要整段照抄）：

1. 这只产品不承诺保本保收益（产品事实）。
2. 过往业绩并不预示未来表现；这次给的是短期数据。
3. 是否赎回由客户结合自己的情况决定。

## 三、敏感问题的标准口径

| 客户的问题 | 回答要点 |
|---|---|
| 是不是产品不行 | 不下"行"或"不行"的结论。给事实：产品本身的区间数据、和同类平均的对比及其局限；说明这类产品的特征 |
| 要不要马上赎回 | 不替客户决定（C03）。给判断办法（P10），提出可以帮客户查清的信息 |
| 后面会不会涨回来、还会不会跌 | 无法预测（C02）；过往业绩不预示未来表现 |
| 为什么会跌 | 只讲材料给出的原因；没给的，说明这类产品会受市场波动影响，具体原因确认后答复（C07、P12） |
| 当初不是说很稳吗、不是保本的吗 | 如实说明产品不承诺保本保收益；不争辩。客户称购买时被告知保本的，按升级条件处理 |
| 和别家的产品比怎么样 | 只引用同类平均数据，不评价其他机构和产品（C06） |
| 能不能换一只 | 不主动推荐（C11）；客户明确要求的，另行按适当性流程办理 |

## 四、升级条件

遇到以下任一情况，客户经理应按机构内部流程上报或转交，不再自行答复：

- 客户表示要投诉，或情绪激烈。
- 客户称购买时被告知保本、保收益，或称未做风险测评、测评不是本人完成。
- 客户反复要求保证收益、预测涨跌，或要求书面承诺。
- 客户对风险等级或适当性匹配结果有异议。
- 客户要求赔偿或补偿。

## 五、语气和用词

- 口语化，像当面或电话里说的话。不用书面套话，不用网络用语。
- 每一版 200–350 字。先回应客户的问题，不绕圈子。
- 不说绝对的话（"一定""肯定""绝对"）。
- 对客内容里不出现内部用语和来源标签，比如"适当性匹配""C03""法规原文"。需要说的换成通俗说法，例如"风险测评结果"。
